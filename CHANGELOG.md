# Changelog

## 2.5.0 — 2026-09

- Rebuilt the desktop interface with PyQt5 while retaining the core V2.4 workflow.
- Added a responsive, scrollable UI and unified visual styling.
- Added a visual point-symbol library with configurable symbol color and scale.
- Embedded generated PNG symbols directly in KMZ for offline display.
- Added five label-position modes: Auto, Centroid, Point on Surface, Envelope Center, and Vertex Average Center.
- Improved GDAL 3+ coordinate-axis handling.
- Preserved field-based coloring and grouped KMZ export.
- Added copyright notice: Copyright (c) 2026 Zhang Y.H.
- Published the complete Python source code.
- Licensed the V2.5.0 source under GNU GPL v3.0.

## 2.4

- Published the author-supplied Windows RAR package without changing its contents.
- Added separate English and Simplified Chinese documentation, direct download, checksum and community QR images.
